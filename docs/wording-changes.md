# 網站用詞：不說「活動」「舉辦」

企劃簡報裡有一句：「不是多一個活動，而是生活裡的一段兄弟時光」。所以網站上盡量不說「活動」「舉辦」，也不用「辦」來講「辦一場」。

改的原則：

- 「兄弟時光」是總稱，每一種就是「一段兄弟時光」，或直接叫它的名字。
- 動詞用「約、聚、開始、過、帶」，不用「辦、舉辦」。
- 每一句看它要做什麼，再用講話的方式改，不是把字直接換掉。
- 故事卡、話題卡上的字一字不改；16 個名字也不改（要跟問卷選項一模一樣）。

下面每一處改動只列一次。「位置」寫的是檔案和欄位，括號裡是它在網站上出現的地方。
