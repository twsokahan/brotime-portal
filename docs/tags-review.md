# 16 個活動的標籤（已確認）

這些標籤會用在入口的『幫我挑』和活動牆的篩選。使用者已在 2026-10-21 看過，確認結果見下一節，資料檔已照著改好。

- 『依據』欄裡用「」框起來的都是原句，一字不差抄自企劃案或簡報。
- 標（推測）的，是資料裡沒寫、照活動性質猜的值；依據寫『使用者確認』的，是使用者看過後同意或改定的。

## 確認結果（2026-10-21）

1. **爸爸帶娃日的地點**：確定只在室內辦。之前討論過，因為安全和方便交流，暫時不考慮親子館或公園。只在室內辦，所以下雨也不影響。
2. **『聊』怎麼標**：照提議，只標在聊天本身就是重點的活動；跑步、登山、採收、手作、烤肉只標它主要在做的事。
3. **還沒有企劃案的 5 個**（桌遊之夜、新春拜年團、田園烤肉會、家族辦桌拜年、巷口泡茶會）：照提議的標籤。
4. **師傅手藝教室**：改成『不適合帶小孩』，因為要用刀具和電動工具。
5. **時段的推測**：照提議。兩個拜年活動用『週末白天』代表春節假期白天；田園烤肉會、師傅手藝教室、巷口泡茶會加『時間不固定』；男人的廚房除了『平日下班後』也標『週末白天』。
6. **河濱夜跑・單車的雨天**：維持『雨天延期』，下雨怎麼辦那句不變。

## 標籤怎麼讀

- **帶小孩**：『適合帶小孩』是活動本來就為親子設計；『可以帶小孩』是歡迎帶，但孩子不是主角；『不適合帶小孩』的活動，有人回答『會帶小孩』時，『幫我挑』不會推薦它。
- **雨天**：下雨也能辦／雨天改地點／雨天延期。不是『下雨也能辦』的，後面那句會顯示在活動頁的『下雨怎麼辦』。
- **時間不固定**：哪天都能辦，適合排休、輪班的區。標了它，『幫我挑』不會因為時段把這個活動排除。
- **興趣**：吃、動、聊、玩、手作。
