# 登入與各區統計：設計文件

2026-11-03｜狀態：使用者已回答第 9 節的問題，可以寫實作計畫。已經過一輪實作者角度的審閱。

## 1. 為什麼要做

2026-11 創價班企劃會有兩項回饋：

- **鎖權限**：負責人希望網站主要給辦兄弟時光的人用，只限創價班通訊錄裡的人。這是負責人提的，使用者自己覺得沒必要鎖，所以選了最輕的做法（見第 5 節）。
- **各區統計**：參加者問卷新增「下一次，你想參加哪一種兄弟時光？」（可複選、選填），要統計給區負責人。區負責人會在兩個時刻看：區會排下個月要約什麼的時候、辦完一場回頭看大家的反應。

登入做好之後，網站就知道是誰、是哪一區的負責人，所以統計直接做在網站上，跟登入一起上線（使用者 2026-11-03 決定，不另做統計試算表）。

## 2. 目標、非目標、反目標

**目標**

- 名單上的人用 Google 帳號登入一次，同一支手機之後不用再登入。
- 不在名單上的人看到友善的說明：用哪個信箱登入的、怎麼加進名單。
- 登入的區負責人看得到自己區的參加者問卷統計。

**非目標**

- 真正的存取控制。網站照樣放在 GitHub Pages、repo 照樣公開，直接打檔案網址或看 GitHub 仍然拿得到內容。使用者知道而且接受：負責人要的是「網站給辦的人用」，擋住隨手點進來的人就夠了。比較過、沒選的做法：網頁上的共用通關密語（密語會被轉傳）、搬到 Cloudflare Pages 由伺服器檢查（真的擋住，但要搬家、repo 改不公開）。
- 搬家、伺服器端驗證、付費服務。

**反目標：出現以下情況就算失敗**

- 名單裡的信箱出現在網頁、前端程式或 repo 裡。
- 當天模式在山上、溪邊沒訊號時，因為登入而打不開。已經登入過的手機，沒訊號也要能用。
- 故事卡頁要登入（主持人會把故事卡頁分享到 LINE 群組給新朋友）。
- 從故事卡頁誤點進來的參加者，被冷冰冰的「無權限」擋下。
- 長得像後台系統或公文。

## 3. 誰能進來

名單是三份合起來：

1. **創價班通訊錄**：約 80 人（創價班企劃組、圈負責人、區負責人），有區別、職務、信箱。
2. **男子部幹部名單**：圈區級幹部約 330 人（使用者說他們被擋在外面很奇怪），有圈、區、職務，信箱有兩欄。
3. **補充名單**：第三份 Google 試算表，放不是幹部、但會帶兄弟時光的主持人，以及名單上登記的不是 Google 帳號的人補來的 Gmail。**區負責人自己加，不經企劃室審核**（使用者 2026-11-03：「我們審不完，也不可能真的認識全國那麼多人」）。怎麼加見第 6 節「加一位主持人」。

兩份試算表的位置與欄位記在企劃室本機，不放進這個公開 repo。比對前要整理信箱：有的格子夾雜文字（「事務長信箱 ……」「……（主）」）、有全形「＠」、有第二個信箱欄。做法是從儲存格用正規式抽出信箱、全形轉半形、轉小寫，兩個信箱欄都算。兩份名單合起來約 340 人，約有 20 人登記的不是 Google 帳號（Yahoo、Hotmail 等）或沒填，要另外補 Gmail。台大、成大的學校信箱（g.ntu、gs.ncku）是 Google 帳號，可以登入。

## 4. 哪些頁要登入

- **要登入**：首頁、`all/`、活動頁（含當天模式）、電子一番賞。
- **不用登入**：故事卡頁（`a/<id>/cards/<card>/`）、新手小抄頁（`a/<id>/guide/`，會分享到 LINE 給參加者）、卡片圖與 PDF 等檔案（本來就擋不住）、問卷（Google 表單，不在這個網站）。

## 5. 登入怎麼做（使用者 2026-11-03 定案：Google 輕登入）

- 網頁用 **Google Identity Services**（「使用 Google 帳戶登入」按鈕）在瀏覽器裡登入，拿到 Google 簽發的 ID token。OAuth 用戶端 ID 建在 GCP 專案 `sokahan`，授權的 JavaScript 來源是正式網域和本機預覽。
- 網頁把 ID token 送到一支 **Google Apps Script 網頁應用程式**。它驗證 token（確認發給本站的用戶端 ID、沒過期），取出信箱比對名單，回傳「在不在名單上」、信箱，以及這個人負責的圈、區。名單不會離開 Apps Script。
- Apps Script 由讀得到兩份名單和問卷回覆試算表的帳號部署（以部署者身分執行、任何人都能呼叫）。
- 結果存在手機上，之後打開網站直接放行，不必每次問 Apps Script。沒訊號時，登入過的手機一樣放行。
- LINE 內建瀏覽器不讓 Google 登入。入口、活動頁已經會改用手機瀏覽器開（`leave-line`），跳不過去時頁面頂端有提示；登入按鈕在 LINE 裡要改成提示「請用手機瀏覽器開」。

## 6. 畫面（草稿使用者看過）

草稿在本機 `.superpowers/brainstorm/9248-1793700085/content/login-screens.html`。

**第一次打開**：標題「下個月，約兄弟做什麼？」；一句「這裡是給各區帶兄弟時光的人用的。請用創價班通訊錄上登記的 Gmail 登入。」；Google 登入按鈕；小字「通訊錄上登記的不是 Gmail，或還沒登記？請你們區的區負責人在網站上把你的 Gmail 加進名單。」

**登入了但不在名單上**：
- 標題「這個帳號還不在名單上」。
- 寫出用來登入的信箱，再說名單照創價班通訊錄；「你也會帶兄弟時光的話，請把上面這個信箱傳給你們區的區負責人，請他在網站上把你加進名單。」
- 兩顆按鈕：「複製這個信箱」「換一個 Google 帳號」。
- 最後一行：「只是想看故事卡？主持人分享給你的故事卡連結，不用登入就能看。」

**加一位主持人**（我的判斷：做在網站上，不把試算表開放給幾百位幹部編輯，免得誤刪別區的人）：
- 看得到某一區統計的人（第 7 節的規則），就能替那一區加人。
- 貼上對方的 Gmail（名字選填）就加好，不用審核。網站記下是哪一區、誰加的、哪一天，寫進補充名單。
- 列出這一區加過的人，可以拿掉。
- 加進來的人可以登入、可以用當天模式，看不到統計。

文字規則：不寫「企劃室」（使用者 2026-11-03 要求，`tests/content.test.mjs` 會擋），避開「活動」「舉辦」（見 `docs/wording-changes.md`）。

## 7. 各區統計

資料來源是參加者問卷的回覆試算表。它不分享給區負責人；統計由同一支 Apps Script 算好，只回傳登入者看得到的區的數字。

**誰看得到哪一區**（使用者 2026-11-03 同意）：區負責人和區幹部看自己區；圈負責人和圈幹部看圈內各區；創價班企劃組和總部幹部看全部；補充名單上的主持人看不到統計。用名單裡的職務和所在圈、區判斷。

**排下個月的時候**：區負責人登入後，首頁「這一季主打」上面多一小塊「你們區的人想約」，列出參加者在「下一次，你想參加哪一種兄弟時光？」勾最多的幾個，讓他跟主打擺在一起比。算的是**最近三場加起來**（使用者 2026-11-03 決定），寫「根據最近 3 場、共 N 份問卷」：只看最新一場人太少、會被那一場的人帶偏（剛打完球的人會一面倒勾看球）；全部加總會越來越舊，常來的人也會被重複算。新的一場進來，最舊那場就退出。單場的結果在下面的回顧頁看，回顧頁也列那一場的「下一次想參加哪一種」。

**辦完一場回頭看**：每一場有一頁回顧，列出那一場參加者問卷的結果：
- 今天有沒有人認真聽你說話？
- 今天有沒有跟至少一個人變得更熟？
- 跟印象中的創價班活動比起來？
- 下次類似的活動，你會想再來嗎？

「今天有沒有一句話或一個瞬間留在心裡？」**不給區負責人看**（使用者 2026-11-03 決定），只有企劃室在回覆試算表看。

問卷沒有「哪一場」這個欄位，所以一場是指「同一區、同一個活動、同一天」的回覆。參加者問卷的「你所在的區」是選填，沒填區的回覆統計不到。

## 8. 留給實作的人決定

- 登入結果在手機上存多久、什麼時候在背景重新確認一次（例如名單有人被拿掉）。
- 確認登入之前頁面怎麼顯示，避免內容先閃一下才被擋住。
- Apps Script 怎麼快取名單和統計，回應要快。
- 「你們區的人想約」列幾個。

以下是我（Claude）先定的，使用者可以推翻：

- **區名對照**：問卷的區名（「花蓮區」）、通訊錄的區別（「花蓮區」）、幹部名單的區名（「花蓮」「北東」「高北」）寫法不同。對照表放在 Apps Script，以問卷 `DISTRICTS` 的寫法為準。
- **讀回覆表**：照題目標題找欄，不靠欄的位置（題目會改名、會新增）。活動名稱跟網站的 `name` 一字不差（測試鎖住），網站用名稱對回活動。複選題的儲存格用「, 」分隔，活動名稱裡沒有逗號。
- **一場的日期**：用送出時間換成台灣日期。
- **驗證 ID token**：呼叫 Google 的 tokeninfo 端點，確認 `aud` 是本站的用戶端 ID、`email_verified` 為真。瀏覽器呼叫 Apps Script 用 `text/plain` 送出，避開預檢。
- **回覆太少不顯示**：一場少於 3 份時只寫「回覆還不夠」，不列數字，免得等於點名。
- **手機上的登入紀錄可以被手動改**：輕登入本來就擋不住懂的人，不處理。

## 9. 使用者的決定（2026-11-03）

1. 不是幹部的主持人：另開第三份試算表當補充名單，區負責人自己加、不經審核（見第 3、6 節）。
2. 誰看得到哪一區的統計：照提案（見第 7 節）。
3. 「留在心裡的一句話」：先說好，隨即改成不給區負責人看（見第 7 節）。
4. 首頁「你們區的人想約」：最近三場加起來（見第 7 節）。
